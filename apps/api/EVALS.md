# Evals

Prompt v3 is evaluated by `python -m evals.extraction.run --prompt-versions v3` from `apps/api/`, which sweeps the golden cases in `tests/golden/` against the default model matrix at a frozen `today=2026-05-10`. OpenAI models (`gpt-4o-mini`, `gpt-4o`) run through Instructor in **TOOLS mode** because OpenAI enforces the response schema via native function calling. Groq models (`llama-3.3-70b-versatile`, `llama-3.1-8b-instant`) run in **JSON mode** because Groq's tool-call validator rejects valid Pydantic-conforming outputs (e.g. it 400s on `"start_time": "2026-05-22T15:00"` as "not valid 'date-time'"). Per-provider mode defaults live in `_PROVIDER_CONFIG` in `app/services/extraction.py`; override per-run with `--mode JSON|TOOLS`. Each run appends one row per (case, model) to `evals/extraction/results.jsonl` for later analysis. Browse the results in the admin app at `/evals` (with a **Golden set** tab for the dataset's input text + expected results), which reads them through the admin-gated `/api/admin/evals/*` endpoints.
